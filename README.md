# Safe Home Agency — აგენტების ტასკ-მენეჯმენტის ბოტი

მარტივი სისტემა Telegram + Google Sheets-ზე: ადმინი (ლაშა) ქმნის დავალებებს,
აგენტები იღებენ შეტყობინებას Telegram-ში, ხედავენ თავიანთ დავალებებს და
ხურავენ, როცა დასრულებულია. ყველაფრის „წყარო" — ერთი Google Sheet.

ეს ინსტრუქცია დაწერილია იმ ვარაუდით, რომ პროგრამისტი არ ხართ — გაყევით
ნაბიჯებს ზუსტად ამ თანმიმდევრობით.

---

## რა გჭირდებათ

1. Telegram ანგარიში
2. Google ანგარიში (Gmail)
3. უფასო ანგარიში [Railway.app](https://railway.app)-ზე (ბოტის მუდმივად
   გასაშვებად — ის მუშაობს 24/7-ზე, თქვენი კომპიუტერის ჩართვა არ არის საჭირო)

---

## ნაბიჯი 1 — Telegram ბოტის შექმნა

1. Telegram-ში მოძებნეთ **@BotFather** და დაუწერეთ `/newbot`.
2. მისცეთ სახელი (მაგ. `Safe Home Agency CRM`) და username (უნდა მთავრდებოდეს
   `bot`-ზე, მაგ. `safehome_agency_bot`).
3. BotFather დაგიბრუნებთ **ტოკენს** — ასე გამოიყურება:
   `123456789:AAExampleTokenString...`. ეს ჩაინიშნეთ, დაგჭირდებათ.

## ნაბიჯი 2 — თქვენი (ადმინის) Telegram chat_id-ის მოძებნა

1. მოძებნეთ **@userinfobot** Telegram-ში და დაუწერეთ `/start`.
2. დაგიბრუნებთ თქვენს `Id`-ს (მაგ. `987654321`) — ეს არის `ADMIN_CHAT_IDS`.

## ნაბიჯი 3 — Google Sheet-ის შექმნა

1. გახსენით [sheets.google.com](https://sheets.google.com) და შექმენით ახალი,
   ცარიელი ცხრილი. დაარქვით, მაგალითად, „Safe Home CRM".
2. URL-ში დააკვირდით ასეთ ნაწილს:
   `https://docs.google.com/spreadsheets/d/`**`1AbC...XyZ`**`/edit`
   — გამორჩეული ნაწილი (`1AbC...XyZ`) არის თქვენი `GOOGLE_SHEET_ID`. ჩაინიშნეთ.
3. Tab-ების (Agents, Tasks) და სვეტების შექმნა არ არის საჭირო ხელით —
   ბოტი პირველივე გაშვებისას თავად შექმნის მათ სწორი სათაურებით.

## ნაბიჯი 4 — Google სერვის-აქაუნთის შექმნა (რომ ბოტმა შეძლოს ცხრილთან წვდომა)

1. გახსენით [Google Cloud Console](https://console.cloud.google.com/) და
   შექმენით ახალი პროექტი (ზედა ზოლში „Select a project" → „New Project").
2. მარცხენა მენიუდან: **APIs & Services → Library**. მოძებნეთ და ჩართეთ
   (Enable) ორივე:
   - **Google Sheets API**
   - **Google Drive API**
3. **APIs & Services → Credentials → Create Credentials → Service account**.
   მისცეთ ნებისმიერი სახელი (მაგ. `crm-bot`) და დააჭირეთ „Done".
4. სიაში გახსენით ახლად შექმნილი სერვის-აქაუნთი → ჩანართი **„Keys"** →
   **„Add Key" → „Create new key" → JSON**. ჩამოიტვირთება `.json` ფაილი —
   ეს ინახეთ უსაფრთხოდ (ეს არის „პაროლი", ნურავის გაუზიარებთ).
5. იმავე გვერდზე დააკოპირეთ სერვის-აქაუნთის **email მისამართი**
   (გამოიყურება ასე: `crm-bot@your-project.iam.gserviceaccount.com`).
6. დაბრუნდით თქვენს Google Sheet-ში (ნაბიჯი 3) → **Share** ღილაკი →
   ჩასვით სერვის-აქაუნთის email → მიეცით **Editor** უფლება → Share.
   (ამის გარეშე ბოტი ცხრილს ვერ ნახავს.)

## ნაბიჯი 5 — ბოტის განთავსება Railway-ზე

1. შედით [railway.app](https://railway.app)-ზე და დარეგისტრირდით
   (მოსახერხებელია GitHub ანგარიშით).
2. **New Project → Deploy from GitHub repo** — თუ ეს ფაილები GitHub-ზე ჯერ
   არ გაქვთ ატვირთული, უმარტივესია: **New Project → Empty Project**, შემდეგ
   საწყისი ეკრანიდან აირჩიეთ **„Deploy from local directory"** ან ატვირთეთ
   ეს ფოლდერი GitHub-ის ახალ repo-ში (github.com → New repository →
   ატვირთეთ ეს ფაილები → Railway-ში `Deploy from GitHub repo`).
3. პროექტის **Variables** ტაბში დაამატეთ:

   | სახელი | მნიშვნელობა |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | ნაბიჯი 1-ის ტოკენი |
   | `ADMIN_CHAT_IDS` | ნაბიჯი 2-ის chat_id (თუ რამდენიმე ადმინია, მძიმით: `111,222`) |
   | `GOOGLE_SHEET_ID` | ნაბიჯი 3-ის ID |
   | `GOOGLE_SERVICE_ACCOUNT_JSON` | გახსენით ნაბიჯი 4-ის `.json` ფაილი ტექსტ-რედაქტორში, მთელი შიგთავსი დააკოპირეთ და ჩასვით აქ (ერთ ხაზად) |
   | `TIMEZONE` | `Asia/Tbilisi` |

4. Railway ავტომატურად წაიკითხავს `Procfile`-ს და გაუშვებს `python bot.py`-ს
   `worker`-ის სახით. Deploy-ის დასრულებისას ლოგებში უნდა დაინახოთ
   `ბოტი გაშვებულია...`.

**შენიშვნა:** Railway-ის free tier თვეში გარკვეულ საათებს იძლევა უფასოდ —
მცირე გუნდისთვის საკმარისია. საჭიროების შემთხვევაში მოგვიანებით შეგიძლიათ
გადახვიდეთ ფასიან გეგმაზე ან სხვა მასპინძელზე (Render, Fly.io) — კოდი არ
იცვლება.

## როგორ გამოვიყენოთ

**თქვენთვის (ადმინი):**
1. მოძებნეთ თქვენი ბოტი Telegram-ში, დაუწერეთ `/start`.
2. `/addagent` — დაამატეთ თითო აგენტი (სახელი + ტელეფონის ნომერი, ზუსტად
   ისეთი, როგორითაც თავად იცნობთ მას — ამ ნომრით მოხდება მისი ავტომატური
   ამოცნობა რეგისტრაციისას).
3. სთხოვეთ თითოეულ აგენტს, გახსნას ბოტი და დაწეროს `/start` — გამოეთხოვება
   ნომრის გაზიარება ღილაკით, ერთი შეხებით.
4. `/newtask` — შექმენით დავალება: სათაური → აღწერა → აირჩიეთ აგენტი
   ღილაკიდან → პრიორიტეტი → ვადა. აგენტს შეტყობინება მისვლას წუთამდე
   სჭირდება.
5. `/agents` — ვინ არის დარეგისტრირებული. `/report` — მოკლე სტატუსი
   ნებისმიერ დროს (ავტომატურადაც მოგივათ დილაობით).

**აგენტისთვის:**
- `/mytasks` — მისი ღია დავალებები.
- დავალების დახურვა: უბრალოდ დააჭირეთ `/done_XXXXXXXX` ლინკს
  (ეგზავნება `/mytasks`-ის პასუხში), ან ხელით `/done XXXXXXXX`.

**პირდაპირ ცხრილში მუშაობაც შესაძლებელია** — თუ Tasks tab-ში ხელით
დაამატებთ ახალ სტრიქონს (`assigned_to`-ში ჩაწერეთ აგენტის `agent_id`,
რომელსაც Agents tab-ში ნახავთ), ბოტი მას წამოიღებს და აგენტს
შეატყობინებს ისევე, თითქოს `/newtask`-ით შეიქმნა.

## რა შემდეგ (თუ დაგჭირდებათ გაფართოება)

ეს არის საწყისი ვერსია — აგენტების ტასკ-მენეჯმენტი. მომავალში ამავე
საძირკველზე (იგივე Sheet, იგივე ბოტი) დამატებით შეიძლება:
- Slack-ში დუბლირებული შეტყობინებები;
- კანდიდატების საკადრო voronka-ს (application → interview → training →
  hiring) ავტომატური დღიური დაიჯესტი;
- სტატუსების უფრო დეტალური ისტორია/ანალიტიკა.

დამატებითი ფუნქციონალი სთხოვეთ ცალკე — უკვე მზა კოდზე დაშენდება.

## ფაილების სია

- `bot.py` — ბოტის მთავარი ლოგიკა (ბრძანებები, შეტყობინებები)
- `sheets.py` — Google Sheets-თან კომუნიკაცია
- `config.py` — environment variable-ების წაკითხვა
- `requirements.txt` — საჭირო Python ბიბლიოთეკები
- `.env.example` — ნიმუში, რომელი ცვლადებია საჭირო (ლოკალურად გასაშვებადაც,
  თუ ოდესმე მოგინდებათ `python bot.py` საკუთარ კომპიუტერზე გაშვება)
- `Procfile` — ეუბნება Railway-ს, როგორ გაუშვას ბოტი
