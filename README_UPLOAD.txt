ამ საქაღალდეში ყველაფერია:
  - ხელშეკრულებების მოდული
  - გუნდების გამიჯვნა (მენეჯერის ექაუნთზე მხოლოდ მისი გუნდი)
  - ფინანსური ტრეკერი (მხოლოდ დირექტორისთვის)
  - ss.ge მხარდაჭერა: Mini App-ში "MyHome" ტაბზე ახალი არჩევანი (წყარო: MyHome/ss.ge; დადება: MyHome / ss.ge / ორივე)
(წინა საქაღალდეები UPLOAD_9_FILES / UPLOAD_TEAM_SCOPE აღარ გჭირდებათ.)

ss.ge-ს მხარდაჭერის ჩასართავად აუცილებელია ორივე:
  1) ეს ფაილები GitHub-ზე + Redeploy (schema.sql ბაზაში 3 ახალ სვეტს თავად დაამატებს; Google Sheets-ზე — ბოტის გაშვებისას).
  2) ექსთენშენის გადატვირთვა ყველა Chrome-პროფილში (chrome://extensions -> "Safe Home" -> ↻), მაგრამ არა მაშინ, როცა job მუშავდება.
     ამავე პროფილში უნდა იყოს შესული home.ss.ge-ზე (ისევე, როგორც MyHome-ზე). ss.ge-ზე კონტაქტად ექაუნთის დადასტურებული ნომერი გამოჩნდება.

ფინანსური ტაბის ჩასართავად (ერთხელ):
  Railway -> Variables -> New Variable: სახელი FINANCE_CHAT_IDS (სივრცის/=-ის გარეშე), მნიშვნელობა — შენი Telegram ID (ციფრები). მერე Redeploy.

=== ახალი: Safe Home Property Hub (ტაბი "განცხადებები" Mini App-ში) ===
ახალი ფაილები: listings_model.py, listings_store.py, listings_api.py (+ შეცვლილი: app.js, style.css, webserver.py, config.py). ატვირთეთ ყველა ერთად GitHub-ზე -> Redeploy.
- ცხრილი "Listings" Google Sheets-ში ავტომატურად შეიქმნება პირველი გახსნისას.
- ძველი განცხადებების შესატანად: ადმინი (არა თიმლიდერი) -> ტაბი "განცხადებები" -> "ძველი განცხადებების შემოტანა" (ერთხელ; განმეორებით არაფერს ამატებს).
- ახალი ატვირთვები კატალოგში ფოტოებითა და კოორდინატებით (რუკისთვის) მხოლოდ ექსთენშენის გადატვირთვის შემდეგ ხვდება (runner.js შეიცვალა) — გადატვირთეთ, როცა job არ მუშავდება.
- სიახლის ზღვრები (დღე): ნაგულისხმევი 3 / 14 / 60. შეცვლა Railway Variables-ით: HUB_FRESH_DAYS, HUB_MID_DAYS, HUB_STALE_DAYS (არასავალდებულო).
- რუკა იყენებს OpenStreetMap-ს და Leaflet-ს (cdnjs.cloudflare.com) — ინტერნეტი ტელეფონზე საჭიროა; ფასიანი სერვისი არ ჩაირთო.

=== ახალი: შეხვედრები განცხადებიდან (Property Hub, ეტაპი 2) ===
ახალი ფაილები: hubmeet_model.py, hubmeet_store.py, hubmeet_api.py, hubmeet_jobs.py (+ შეცვლილი: app.js, style.css, webserver.py, config.py, bot.py). ატვირთეთ ყველა ერთად -> Redeploy.
- ცხრილი "HubMeetings" Google Sheets-ში ავტომატურად შეიქმნება. ძველი შეხვედრების ბოტი (/meeting) და ცხრილი უცვლელია; Hub-იდან დაგეგმილი შეხვედრა ძველ "Meetings" ცხრილშიც იწერება (KPI/ისტორია/ხელშეკრულება/CRM მუშაობს).
- ბოტი თავისით გააგზავნის შეხსენებებს: შეხვედრამდე ~90 წთ-ით ადრე და შედეგის ჩაწერის შეხსენებას (3 საათის მერე).
- ექსთენშენის გადატვირთვა ამ ეტაპისთვის დამატებით არ არის საჭირო (მიდის წინა ეტაპის runner.js-ით).

=== ახალი: ფავორიტები სერვერზე, ზღვრების პანელი, CSV ექსპორტი (ეტაპი 3) ===
ახალი ფაილი: hubprefs.py (+ შეცვლილი: app.js, webserver.py, listings_model.py). ცხრილები "HubFavs" და "HubSettings" ავტომატურად შეიქმნება.
- ფავორიტები ყველა მოწყობილობაზე ერთნაირია.
- ადმინი (არა თიმლიდერი) -> განცხადებები -> ზედა ბარათი: "⚙️ სიახლის ზღვრები" (ახალი/საშუალო/ძველი დღეებში) და "⬇️ CSV" (ფაილი Telegram-ში მოდის).

=== გაშვების თანმიმდევრობა ===
1) ყველა ფაილი GitHub-ზე -> Railway Redeploy (ბოტიც თავისით გადაიტვირთება).
2) Mini App გახსენით -> ტაბი "განცხადებები" -> ადმინი: "📥 ძველი განცხადებების შემოტანა" (ერთხელ).
3) ექსთენშენი გადატვირთეთ (job-ის გარეშე დროს) და გაუშვით 1 ახალი განცხადება — ფოტოთი/რუკაზე გამოჩნდება.
4) ტესტი: ბინა -> "📅 შეხვედრა" (საკუთარზე), მერე სხვა აგენტის ბინაზე თანამშრომლობით -> მფლობელი ადასტურებს -> "ხელშეკრულება" შეხვედრის ბარათიდან.
