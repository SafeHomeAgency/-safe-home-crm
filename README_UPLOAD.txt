ატვირთვა GitHub-ზე (ყველა ფაილი ერთად, ძველებს ჩაანაცვლებს) — შემდეგ Railway-ზე Redeploy.

ამ საქაღალდეში ყველაფერია: ხელშეკრულებების მოდული + გუნდების გამიჯვნა (მენეჯერის ექაუნთზე მხოლოდ მისი გუნდი) + ახალი ფინანსური ტრეკერი.
(წინა საქაღალდეები UPLOAD_9_FILES / UPLOAD_TEAM_SCOPE აღარ გჭირდებათ — ეს ყველაფერს მოიცავს.)

ფინანსური ტაბის ჩასართავად (ერთხელ):
1) Railway -> პროექტი -> Variables -> ახალი ცვლადი:  FINANCE_CHAT_IDS = <შენი Telegram ID>
   (ID რომ არ გახსოვდეს: ატვირთვის შემდეგ Mini App-ში ადმინს გამოუჩნდება "💰 ფინანსები" ტაბი ინსტრუქციით და შენი ID-ით.)
2) Redeploy, შემდეგ Mini App თავიდან გახსენი.
3) სანამ FINANCE_CHAT_IDS არ არის დაყენებული, ფინანსურ მონაცემებზე წვდომა არავის აქვს.
   დაყენების შემდეგ — მხოლოდ ამ ID-ს (მრავალი ID: მძიმით გამოყავი).

პირველ გაშვებისას ბოტი თავად შექმნის Google Sheets-ში ტაბებს: FinDeals, FinExpenses, FinSettings.
